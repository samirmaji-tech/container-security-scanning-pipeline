Container Security Scanning Pipeline

This sample web page is packaged into a Docker image. The project scans that image with Trivy to identify known vulnerabilities before it is promoted for deployment.

Pipeline stages

  1. Build the Docker image.
  2. Scan the image with Trivy.
  3. Generate a human-readable report.
  4. Review HIGH and CRITICAL findings before release.

Demo note: this page is a sample application; the security value comes from scanning the image that packages it.
